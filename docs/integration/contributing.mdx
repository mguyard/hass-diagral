Want to contribute to the `Diagral` integration? Great! Bug reports, feature requests and pull requests are all welcome.

<Steps>
  <Step title="Read the contributing guide">
    The [contributing guide](https://github.com/mguyard/hass-diagral/blob/dev/CONTRIBUTING.md) explains how to set up your environment, the checks to run, the commit format and the ground rules.
  </Step>
  <Step title="Work from the dev branch">
    Fork the repository, create your branch from `dev`, and add or update the tests that cover your changes.
  </Step>
  <Step title="Open a pull request against dev">
    Fill in the template: what changed, why, and how you verified it. Every commit must be signed.
  </Step>
</Steps>

<Success>
🎉 Once your PR is reviewed and approved, it is merged into the `dev` branch. It then ships in a beta release, and in a stable release after final testing.
</Success>
