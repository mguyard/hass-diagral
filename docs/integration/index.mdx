The integration requires Home Assistant `2026.8` or later. The easiest way to install it is to use [HACS](https://www.hacs.xyz/).

## Automatic install

Once HACS is installed, click the button below to start the automated installation:

[![Open your Home Assistant instance and open a repository inside the Home Assistant Community Store.](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=mguyard&repository=hass-diagral&category=Integration)

## Via the HACS interface

`Diagral` is a default repository within HACS: if you do not wish to use the button above, install it from the HACS interface.

<Steps>
  <Step title="Search for Diagral">
    Open HACS in Home Assistant and search for `Diagral`.
  </Step>
  <Step title="Download it">
    Open the `Diagral` repository and download it.
  </Step>
  <Step title="Restart Home Assistant">
    Home Assistant loads a newly downloaded integration only after a restart.
  </Step>
</Steps>

<Success>
The integration is installed: continue with the [Setup](/integration/setup).
</Success>
